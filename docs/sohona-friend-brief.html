Slide 03 · Main functions

Core features

  • Admin: Google auth, create memorial (name-only), Package A/B/C, QR + setup link
  • Family setup: one-time setup token → PIN set → statements/media → manage link
  • Family manage: PIN session · edit content · delete comments · public PIN toggle
  • Public QR page: view memorial · optional PIN gate · signed media playback · comments
  • Light site: /, /about, /packages, /contact

Slide 06 · Privacy model

ඇයි මේක special?

  • Admin APIs never select statements / media / comments
  • Media DB එකේ r2ObjectKey විතරක් — permanent public URL නැහැ
  • PIN plain-text store නෑ — Argon2id hash only
  • Setup/manage tokens DB එකේ hashed
  • Wrong PIN ×5 → temporary lock · Redis rate limits abuse අඩු කරනවා
Slide 07 · User flow

End-to-end flow

  1. Admin Google login → memorial create + Package A/B/C
  2. Family ට setup link යවනවා
  3. Family PIN set → memories add → setup complete
  4. System manage link දෙනවා + retention years start
  5. Visitors QR / /p/[qrId] එකෙන් memorial බලනවා
  6. Family later manage + PIN එකෙන් edit කරනවා
